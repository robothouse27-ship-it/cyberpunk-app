FULL BODY CONVERSIONS
When a Character goes full chrome, 
replacing the vast majority of their meat 
body, it’s called a Full Body Conversion, or 
FBC for short. FBC cards represent the vast 
number of upgrades that are purchased as a 
suite, and in many ways function like a Gear 
card, but bigger. 
Each model may buy and equip only one 
FBC card. Models with an FBC are Cyber-
Characters.
FBC’s blend the line between man and 
machine, and may be affected by both Heal 
and Repair effects.
FBC’s cannot be looted, either with the Loot 
Gear action or any other means.
ACTIONS, SKILLS, & ARMOR (A)
ACTIONS, SKILLS, & ARMOR (A)
Each FBC may grant one or more bonus 
Action tokens, which add to the number of 
Action tokens available to the model.
The FBC card also lists skills, either as a 
replacement or bonus to the Character’s 
skill. If the skill shown has a “+”, it is added 
to the Character’s total skill value. If the 
skill value has no “+” value, it replaces the 
Character’s final skill value if the FBC value 
is higher, otherwise use the base Character’s 
total value. Each FBC may also have an 
Armor value that replaces the Character’s 
printed Armor value (if the FBC value is 
higher). 
In addition, FBCs already include so many 
Cybernetics that additional Cybergear does 
not always affect them. Any Skill increase 
granted by Cybergear is applied to the base 
Character, before the FBC replaces that skill. 
If the FBC grants a bonus value to a skill, it 
stacks with any Cybergear equipped by the 
Character.
SPECIAL ABILITIES (B)
SPECIAL ABILITIES (B)
The FBC cards also have special abilities 
and actions. The model gains these in 
addition to its own and they work the same 
as abilities and actions printed on Gear or 
Character cards.
